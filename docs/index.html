Kaleidoscope

A lightweight JavaScript plugin for particle backgrounds.

Paste the d attribute of an SVG path

GitHub npm Download

Add to your HTML 
<canvas id="kaleidoscope"></canvas>
<script src="https://cdn.jsdelivr.net/npm/ak-kaleidoscope@2/dist/kaleidoscope.min.js"></script>
<script>
  new Kaleidoscope({ selector: '#kaleidoscope' });
</script>

Or install with npm: npm install ak-kaleidoscope
